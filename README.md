This Python program reads book inventory data from a CSV file, organizes it by genre using custom Book and Author classes, and allows users to view detailed listings of books—including author, title, year, quantity, and price—through an interactive menu.

Key Features:
- Reads and parses inventory data from a CSV file
- Uses object-oriented programming with Book and Author classes
- Displays an interactive genre selection menu
- Shows detailed book listings and calculates total inventory and cost per genre
- Handles user input and invalid data gracefully
